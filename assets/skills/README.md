# Iconos de tecnologías

Los logotipos vectoriales de estas insignias proceden de [Simple Icons](https://github.com/simple-icons/simple-icons), revisión [`90646e4bf7f3`](https://github.com/simple-icons/simple-icons/tree/90646e4bf7f3b89df6c37e65baf3e7bc759a517c/icons).

Simple Icons se distribuye bajo [CC0 1.0 Universal](https://github.com/simple-icons/simple-icons/blob/90646e4bf7f3b89df6c37e65baf3e7bc759a517c/LICENSE.md). Los nombres y marcas pertenecen a sus respectivos titulares; su uso identifica las tecnologías y no implica afiliación.

Se conservaron los trazados originales y se adaptaron tamaño y color a las insignias del perfil. `actions.svg` utiliza el icono `githubactions`.
